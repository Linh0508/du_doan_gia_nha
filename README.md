# 🏠 Dự đoán giá nhà

Một ứng dụng Python để dự đoán **giá nhà ở Việt Nam** dựa trên dữ liệu thực tế.

## 📌 Mô tả

Dự án sử dụng dữ liệu về nhà ở và một mô hình dự đoán để ước tính giá dựa trên các thuộc tính như diện tích, vị trí, số phòng, v.v.

## 🧰 Công nghệ & Thư viện

- Python  
- Flask (hoặc web framework Python)  
- HTML/CSS (giao diện)  
- Pandas, Scikit-Learn (dữ liệu và mô hình)
